One window, two tools

Use Gap and Streak through the tabs in this same BeFree window. Install this main page once, then enter your real numbers from its icon. Browser tabs and installed apps may use different storage.

Install: on iPhone/iPad, open in Safari, use Share, Add to Home Screen and Open as Web App if offered. On Android/desktop, use the browser’s Install option. On recent Mac Safari, use File, Add to Dock. Browser wording and support vary.

Verify: open both tools online, create a test habit linked to completed daily spending, mark today complete in Gap, switch to Streak and check the tick. Reopen the icon and check the data remains. Then try airplane mode and reopen both tabs.

Back up each tool: Settings → Save a backup file. Do this weekly and after setup, big changes or month close. Restore the matching file through that tool’s Settings. Backups replace current data; export current data first. Keep dated copies in a private folder and test restoration using test data before relying on it.

Privacy: no account or bank connection. Financial entries remain in browser storage unless you export them. The site receives normal page/update requests. Local storage and downloaded JSON backups are not encrypted by the app. A PIN hides the screen; it does not encrypt your records. Browser cleanup, private mode, device loss or site changes can erase access.

Existing users: export each old app first. Open the new BeFree icon and restore each file there if data is absent. Review legacy card/payment entries and reconcile balances.
